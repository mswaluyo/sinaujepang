Import Soal dari MHTML / HTML

📄 Parser Google Forms Viewscore → quiz-data.json

Pilih file .mhtml / .html langsung → klik "Ekstrak Soal" → unduh quiz-data.json. Semua proses di browser Anda, data tidak keluar ke server.

1. Masukkan HTML Halaman Score

Bisa langsung pilih file .mhtml hasil ekspor Chrome/Edge, atau file .html hasil copy-paste. Tool akan parsing otomatis.

2. Pengaturan Ekstraksi
Nama Paket Quiz (slug)

Contoh: basu0001-quiz. File akan disimpan di public/basu0001-quiz/quiz-data.json

CSS Selector Soal (opsional, biarkan kosong untuk otomatis)

Contoh: .freebirdFormviewerViewItemsItemItem atau div[role='listitem']

3. Preview Hasil Deteksi
Soal: 0 Gambar: 0 Belum diproses
4. Hasil JSON (quiz-data.json)

Simpan file JSON ke: public/<slug>/quiz-data.json lalu akses quiz via quiz.html?p=<slug>

Cara Kerja
  1. Pilih file .mhtml langsung (hasil ekspor Chrome/Edge) atau file .html — tool akan parsing otomatis.
  2. Jika upload MHTML, gambar akan otomatis diekstrak dari CID → base64 data URI.
  3. Tool mendeteksi otomatis soal, opsi, jawaban benar, dan gambar (base64).
  4. Periksa preview, lalu klik Download quiz-data.json.
  5. Simpan JSON ke public/<slug>/quiz-data.json di proyek Anda.
