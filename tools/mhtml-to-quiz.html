📄 Parser Google Forms Viewscore → quiz-data.json

Buka file MHTML di browser → Simpan sebagai HTML lengkap → Buka isi HTML di sini → Export JSON. Semua proses di browser Anda, data tidak mana-mana.

1. Masukkan HTML Halaman Score
2. Pengaturan Ekstraksi
Slug Paket (nama folder quiz)
Contoh: basu0001-quiz. File akan disimpan di public/basu0001-quiz/quiz-data.json
CSS Selector Soal (biarkan kosong untuk deteksi otomatis)
Contoh: .freebirdFormviewerViewItemsItemItem, div[role="listitem"]
3. Preview Hasil Deteksi
Soal: 0Gambar: 0Belum diproses
4. Hasil JSON (quiz-data.json)
Cara Kerja Singkat
  1. Buka file .mhtml di Chrome/Edge, tekan Ctrl+S, pilih Halaman Lengkap.
  2. Buka file .html hasil simpan di browser, salin semua isi (Ctrl+A, Ctrl+C), tempel di kotak di atas.
  3. Tool akan mencoba deteksi otomatis soal, opsi, jawaban benar, dan gambar (base64).
  4. Periksa preview, lalu download quiz-data.json.
  5. Simpan JSON ke public/<slug>/quiz-data.json di proyek Anda.
